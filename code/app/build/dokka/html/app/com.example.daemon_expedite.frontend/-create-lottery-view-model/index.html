CreateLotteryViewModel

class CreateLotteryViewModel(savedState: SavedStateHandle = SavedStateHandle()) : ViewModel

Holds the Create lottery form and saves it. Also edits an existing lottery when the route has a Routes.LOTTERY_ID_ARG: call startEditing and submit updates it instead.

Call load with the owner and their campsites. Campsites already in another lottery that isn't finished or cancelled are left out of the picker: a campsite can only be in one at a time.
