RegisterCampsiteViewModel

class RegisterCampsiteViewModel : ViewModel

Holds the Register campsite form and saves it.

Also used to edit an existing campsite: call startEditing and the form is filled in from the saved campsite, and submit updates it instead of creating a new one.

Shared by the form screen and the Select location map (the map route gets it from the form route's back stack entry), so the map can write the picked spot straight into the form.
