RegisterCampsiteScreen

@Composable
fun RegisterCampsiteScreen(draft: CampsiteDraft, errors: CampsiteDraftErrors = CampsiteDraftErrors(), isSaving: Boolean = false, isEditing: Boolean = false, onDraftChange: ((CampsiteDraft) -> CampsiteDraft) -> Unit = {}, onAddressChange: (String) -> Unit = {}, onOccupancyChange: (Int) -> Unit = {}, onPriceChange: (String) -> Unit = {}, onAddAmenity: (String) -> Boolean = { true }, onRemoveAmenity: (String) -> Unit = {}, onChooseOnMapClick: () -> Unit = {}, onAddPhotosClick: () -> Unit = {}, onRemovePhoto: (Uri) -> Unit = {}, onRegisterClick: () -> Unit = {}, onCancelClick: () -> Unit = {}, onBackClick: () -> Unit = {})

"Add campsite" form, from the Figma frame "Register campsite · Empty". Also used as the "Edit campsite" form when isEditing is true.

Only draws draft and reports changes; RegisterCampsiteViewModel holds the values and saves them. The location row opens the Select location map.

Parameters

draft

Current form values.

errors

Problems to show under the fields (only filled in after the first submit).

isSaving

True while saving: the register button is disabled and says "Registering…".

isEditing

True when editing a saved campsite: the title and save button change.

onDraftChange

Called with a change to apply to the draft, for example { it.copy(name = text) }.

onAddressChange

Called when the owner types in the address field.

onOccupancyChange

Called with +1 or −1 from the occupancy buttons.

onPriceChange

Called when the owner types a price (the ViewModel keeps only digits).

onAddAmenity

Called with a typed amenity. Returns false if it wasn't added (duplicate).

onChooseOnMapClick

Opens the Select location map.

onAddPhotosClick

Opens the photo picker.
