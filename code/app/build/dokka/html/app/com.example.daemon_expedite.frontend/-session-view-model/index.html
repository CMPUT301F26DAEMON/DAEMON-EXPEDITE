SessionViewModel

class SessionViewModel : ViewModel

Holds the signed-in User for the whole app.

Created once per activity (see AppNavigation) and shared by every screen, so screens never fetch the user themselves. It survives screen rotation, and starts loading as soon as it is created, which also covers Android restoring the app straight onto a later screen.

Every change to the user goes through a function here. Each one changes the User object, saves it with Database.updateUser, then bumps SessionState.Ready.revision so screens redraw. Results are reported through an onResult callback so the screen can navigate or show an error.
