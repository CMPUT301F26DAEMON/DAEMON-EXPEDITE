BookingViewModel

class BookingViewModel(savedState: SavedStateHandle) : ViewModel

Data for the "Make a Reservation" screen, where a lottery winner books their stay or declines.

The lottery id (and the campsite to pick first) come from the route (see Routes.BOOK_LOTTERY_STAY). Booking itself goes through SessionViewModel.bookLotteryStay, because it changes the signed-in user; declining doesn't, so it is done here.
