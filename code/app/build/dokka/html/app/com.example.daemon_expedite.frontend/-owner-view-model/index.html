OwnerViewModel

class OwnerViewModel : ViewModel

Data for the campsite owner screens: the owner record and their registered campsites.

Owners are stored separately from users (the "owners" collection). The first time someone switches to the owner view, an owner record is created from their user details, using the same id so it is easy to match the two up later.
