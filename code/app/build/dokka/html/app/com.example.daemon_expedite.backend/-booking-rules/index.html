BookingRules

object BookingRules

The rules for a lottery winner's booking. Pure functions, so they're easy to test, and run both on the booking screen and again inside the booking transaction.

Nights are counted as in DatePeriod: a booking from 16 Oct to 18 Oct takes the nights of the 16th and 17th, and the 18th is the check-out day.
