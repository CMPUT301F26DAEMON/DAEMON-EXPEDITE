Campsite

class Campsite(val id: Id = Id(), name: String, description: String, tags: List<String> = emptyList(), location: Location, maxOccupancy: Int, policies: String = "", pricePerNight: Int, images: List<Image> = emptyList(), val ownerId: Id, rating: Rating, address: String)

Represents a campsite listing that can be published by an owner and booked through a lottery.

The class keeps track of the campsite's public details, pricing, occupancy limits, and associated images. Its lotteries are found with Database.fetchLotteriesForCampsite.
