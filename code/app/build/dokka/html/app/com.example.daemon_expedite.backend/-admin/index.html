Admin

class Admin(id: Id = Id(), name: String = "", email: String = "", phoneNumber: String = "", notificationsEnabled: Boolean, profileImage: Image? = null, lotteries: List<Id> = emptyList(), reservations: List<Id> = emptyList(), chats: List<Id> = emptyList(), ownerCampsites: List<Id> = emptyList(), ownerReservations: List<Id> = emptyList(), ownerLotteries: List<Id> = emptyList(), sentNotifications: List<Id> = emptyList(), ownerChats: List<Id> = emptyList()) : Owner

A user with moderation powers. Inherits everything from Owner (and so User), which lets an admin act as a user, an owner and an admin, switched by the UI toggle. Adds no state of its own, only the functions to remove content and accounts.

Mutating methods are suspend because they write to the database through Database. If the database call throws, nothing further is done.
