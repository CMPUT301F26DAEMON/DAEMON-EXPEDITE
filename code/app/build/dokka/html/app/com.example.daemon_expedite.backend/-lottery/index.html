Lottery

class Lottery(val id: Id = Id(), val ownerId: Id, campsites: List<Id>, entryStart: Instant, entryEnd: Instant, stayPeriods: List<DatePeriod>, winnerCount: Int, val waitingList: WaitingList = WaitingList(), winners: List<Id> = emptyList(), bookings: List<Booking> = emptyList(), declined: List<Id> = emptyList(), drawn: Boolean = false, cancelled: Boolean = false)

A lottery for one or more campsites.

Timeline:

  1. Entry period (entryStart to entryEnd): entrants join the waiting list.

  2. Draw: at entryEnd a Cloud Function picks winnerCount winners (everyone wins if fewer joined) and sets drawn.

  3. Booking window: until the first night of stayPeriods, each winner can book one campsite for one continuous range of nights, first come first served (see bookings).

  4. Stays: the nights in stayPeriods.

A campsite can only be in one lottery that isn't past (see LotteryPhase.isPast).
