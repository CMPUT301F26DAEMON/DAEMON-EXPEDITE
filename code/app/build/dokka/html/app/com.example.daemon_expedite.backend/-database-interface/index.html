DatabaseInterface

interface DatabaseInterface

Thrown when a document that was asked for does not exist (as opposed to the database being unreachable or a document being malformed).

Callers use this to tell "first launch, nothing saved yet" apart from real errors. Treating every error as "not found" would create a duplicate user or owner and overwrite the real one.
