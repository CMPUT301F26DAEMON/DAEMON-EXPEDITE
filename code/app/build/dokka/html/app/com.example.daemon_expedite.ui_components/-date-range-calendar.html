DateRangeCalendar

@Composable
fun DateRangeCalendar(startDate: LocalDate?, endDate: LocalDate?, onRangeChange: (start: LocalDate?, end: LocalDate?) -> Unit?, modifier: Modifier = Modifier, initialMonth: YearMonth = startDate?.let(YearMonth::from) ?: YearMonth.now(), minDate: LocalDate? = null, maxDate: LocalDate? = null, addedRanges: List<ClosedRange<LocalDate>> = emptyList(), addedRangesColor: Color = AppColors.PrimaryMuted, isDateEnabled: (LocalDate) -> Boolean = { true })

A month calendar for picking a date range (start and end date).

Built from the "Availability calendar" frame in the Expedite Figma file.

The composable is stateless with respect to the selection: it shows whatever startDate and endDate you pass and reports taps through onRangeChange. Taps follow these rules (see nextDateRange):

  • No start yet, or a full range is already chosen: the tapped day becomes the new start.

  • Start chosen, tapped day is after it: the tapped day becomes the end.

  • Start chosen, tapped day is on or before it: the tapped day becomes the new start.

The visible month is kept internally and survives configuration changes.

Usage:

var start by remember { mutableStateOf<LocalDate?>(null) }
var end by remember { mutableStateOf<LocalDate?>(null) }

DateRangeCalendar(
    startDate = start,
    endDate = end,
    onRangeChange = { s, e -> start = s; end = e },
    minDate = LocalDate.now(),
)

Parameters

startDate

First day of the selected range, or null if nothing is selected.

endDate

Last day of the selected range, or null if only a start is selected.

onRangeChange

Called with the new (start, end) pair after a tap. Pass null for a read-only calendar that only shows the range (days can't be tapped, months can still be changed).

modifier

Modifier applied to the calendar card.

initialMonth

Month shown first. Defaults to the month of startDate, or the current month.

minDate

Days before this are greyed out and cannot be tapped. Null means no limit.

maxDate

Days after this are greyed out and cannot be tapped. Null means no limit.

addedRanges

Ranges already chosen (for example by DateRangesPicker), drawn in a lighter green behind the current selection. Each runs from its start to its endInclusive day.

isDateEnabled

Extra rule for which days can be tapped, on top of minDate and maxDate. Days it returns false for are greyed out.

addedRangesColor

Fill for addedRanges. Pass AppColors.Primary on read-only calendars where they are the only thing shown.
