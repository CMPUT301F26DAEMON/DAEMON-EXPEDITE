AppTextStyles

object AppTextStyles

Every text style in the Expedite app, extracted from the Figma file.

Figma has no text styles defined, so these are the roughly 45 unique combinations found in the design, merged into named roles. Where Figma used "Auto" line height the style leaves it unspecified; otherwise the line height is expressed in em so it scales with the font size.

Styles marked "uppercase" were set to uppercase in Figma. Compose has no text-case property, so call .uppercase() on the string you display.
