CampsiteCard

@Composable
fun CampsiteCard(name: String, location: String, pricePerNight: String, imageUrl: String? = null, @DrawableRes imageRes: Int = R.drawable.camp1, modifier: Modifier = Modifier, rating: Double? = null, maxOccupancy: Int? = null, pill: @Composable () -> Unit? = null, action: @Composable () -> Unit? = null, onClick: () -> Unit? = null, containerColor: Color = AppColors.FillField, imageAspectRatio: Float = 2.8f)

One campsite card, used for browsing, reservations and past stays.

The parts that differ between screens are slots, so one composable covers every variant:

  • pill shows a CampsitePill (or anything else) in the photo's top-right corner.

  • action shows a button row under the details, for example your ButtonRed ("Cancel reservation") or ButtonGreen ("Rate Your Stay").

  • onClick makes the whole card tappable and adds the trailing arrow. Leave it null for cards that only show an action.

// Browse card
CampsiteCard(
    name = "Pine Creek Hideaway", location = "Big Sur, California",
    pricePerNight = "$45", rating = 4.9, imageUrl = url, maxOccupancy = 5,
    pill = { CampsitePill("Lottery · Active", variant = PillVariant.Highlight, icon = AppIcons.LotteryTicket) },
    onClick = { openCampsite(id) },
)

// Reservation card
CampsiteCard(
    name = "Pine Creek Hideaway", location = "Big Sur, California",
    pricePerNight = "$45", rating = 4.9, imageUrl = url,
    pill = { CampsitePill("Confirmed") },
    action = { ButtonRed("Cancel reservation", onClick = { cancel(id) }) },
)

Parameters

name

Campsite name.

location

Location line, for example "Big Sur, California".

pricePerNight

Already formatted price, for example "$45".

imageUrl

Web address of the photo, for example Campsite.coverImageUrl. Loaded with Coil.

  • @param imageRes Local drawable shown when imageUrl is null, while the photo loads, and if

  • loading fails. Defaults to the app's placeholder, so most callers never pass it.

modifier

Modifier applied to the card.

rating

Average rating, or null to hide the rating.

maxOccupancy

Maximum guests, or null to hide "(Max Occ: n)".

pill

Optional slot drawn in the top-right corner of the photo.

action

Optional slot drawn at the bottom of the card, full width.

onClick

Called when the card is tapped. When null the card is not clickable and the arrow is hidden.

containerColor

Background of the details area. Use a darker color for browse cards and AppColors.Surface for reservation cards.

imageAspectRatio

Width to height ratio of the photo.
